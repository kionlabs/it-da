# 잇다과외 네이버 검색어 운영 계획 (2026-11-01)

## 자료와 해석

- 원본: `public/files/연관키워드 20261101 2336.xlsx` (네이버 광고주센터 연관키워드 다운로드)
- 월간 검색수는 PC와 모바일을 합산해 검색 수요의 **대략적인 크기**를 비교한다. 광고 경쟁 지표를 자연 검색 난이도로 간주하지 않는다.
- `영어학원`, `강남인강`, `이러닝`처럼 검색량이 크더라도 서비스 형태가 다른 검색어는 과외 페이지의 목표 검색어로 삼지 않는다.

`중2영어과외`처럼 검색량이 작은 세부어는 단순히 지역·학년·과목을 조합한 대량 페이지를 만들 근거가 되지 않는다. 실제 수업 자료와 상담에서 확인한 질문이 쌓일 때 기존 학년별 안내를 확장한다.

## 이번 단계

1. 온라인 과외 허브의 메타 제목·설명을 검색 의도에 맞게 정리한다.
2. 화상 수업의 수업 전·실시간·수업 후 흐름을 본문에 설명한다.
3. 중등 수학의 학년별 학습 지점과 진단 기준을 독립 페이지에 담고, 온라인 허브와 수학 과목 페이지에서 연결한다.
4. 새 페이지를 사이트맵에 포함한다. 각 페이지는 자기 주소를 canonical로 사용한다.

## 다음 순서

1. 국어 과목 페이지: 실제 문의에서 많은 학년·시험 고민을 확인한 뒤 교과서/학교 프린트 활용 예시를 보강한다.
2. 중학생 과외: 학년별 허브에서 중1·중2·중3의 목표 선택을 쉽게 만들고 관련 과목 페이지로 연결한다.
3. 지역·학교 검색어: 제휴 또는 실제 지도 가능 지역, 학교 자료와 상담 내용이 확인된 경우에만 고유한 사례를 만든다. 단어만 바꾼 대량 페이지나 방문 때마다 내용이 바뀌는 페이지는 만들지 않는다.

## 측정

- 배포 후 새 URL의 HTTP 200, `robots` 허용, canonical, 사이트맵 포함을 확인한다.
- 네이버 서치어드바이저에서 새 URL 수집을 한 번 요청하고 수집/색인 상태를 확인한다. 반복 요청으로 순위가 보장되지는 않는다.
- 2~4주 단위로 `온라인과외`, `화상과외`, `중등수학과외`의 노출·클릭·유입 페이지를 기록한다. 검색 결과는 기기와 시점에 따라 달라지므로 개인 검색 순위만으로 판단하지 않는다.
- 모바일 검색 비중이 높은 검색어이므로 모바일에서 제목, 본문, 탐색 링크와 상담 버튼이 가려지지 않는지 점검한다.

검색 첫 페이지 노출은 보장할 수 없다. 이 계획은 검색자의 질문에 답하는 페이지와 검색엔진이 발견할 수 있는 경로를 먼저 갖추는 작업이다.
